# MyMusic

This is an early development foundation, not the completed application. It currently supports saving individual YouTube links, favourites and embedded video playback. Data is stored in the renderer's local storage. Playlists, SQLite, karaoke, local files and the other features in the brief are not yet implemented. Do not rely on this development version for irreplaceable data.

Install dependencies using `npm.cmd install`, build with `npm.cmd run build`, and launch with `npm.cmd start`.
